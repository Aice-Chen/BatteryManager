本轮真实升级发现并修复了静默安装丢失自启项的问题：原先在任务列表创建前设置勾选，后续被 Inno 重置。新实现直接按当前 Run 状态生成默认值，显式任务选择仍交由安装器处理，并保护未知同名启动项。回退到含旧问题的 preview.2 时显式选择自启；恢复 0.2.0 时不传此选项，确认其保留当前登记。

程序内升级的 HTTP 响应由显式本地 fixture 提供，使用实际 0.2.0 安装包，下载、校验、存储和进程交接均真实执行。安装器检查时旧进程已经终止，持有的进程句柄返回结束状态；本轮不把这一结果写成等待仍在运行的进程已获覆盖。

GitHub 远端 CI 已启用，按 PR 和 main 提交触发，避免同一开发提交重复运行；每个提交的实际结果见 [GitHub Actions](https://github.com/Aice-Chen/BatteryManager/actions/workflows/verify.yml)。

尚待单独完成：真实 Windows 注销后登录自启、正式发布后的真实下载。程序与安装器尚未签名。当前用户配置、硬件日志、详细路径和截图留在本机证据目录，不进入公共仓库或发行附件。

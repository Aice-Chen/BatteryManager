# Battery Manager 0.2.0

当前为本地正式候选，尚未在 GitHub 发布。

## 使用变化

- 提供 Windows 11 x64 当前用户安装版，也保留便携 ZIP。
- 设置页增加登录 Windows 时启动的开关，显示 Windows 禁用启动项的状态。
- 覆盖升级保留当前实际的自启选择，关闭过自启后不会因旧安装记录重新开启。
- 支持正式版本检查、下载校验和安装交接。自动检查默认开启，每天最多尝试一次；下载和安装由用户操作。
- 安装版配置集中保存在当前用户的应用数据目录，可显式导入便携版配置；已有安装版配置不会被覆盖。

## 维护变化

- 整理设置、存储、更新协调与采集元数据的模块边界，四种 HID 读取共享扫描生命周期。
- 新构建与完整 Git 提交逐文件绑定，安装器与便携包使用同一负载和安装输入。
- 增加 Windows CI 与本地统一检查入口；本地更新验收模式只在显式指定时启用。

已验证设备范围与电量、连接、过期和关联规则保持不变。此版本未增加其他品牌或未验证型号支持。

## 安装与恢复

先退出旧程序，再运行安装器。迁移便携版时，在安装版设置页选择旧程序目录导入配置，确认名称、类型、优先级和关联后保留旧目录作为回退备份。安装版用户数据不会随卸载自动删除。

便携版更新下载 ZIP，退出后解压到新目录，再复制所需配置。安装版下载完成后可在设置页确认安装；程序等待设置保存及设备读取结束后退出，安装器等旧进程实际结束再替换文件。

程序与安装包尚未代码签名。包内 SHA256 与来源提交记录用于完整性和版本核对，不能替代独立发布者签名。更新来源为 Aice-Chen/BatteryManager 的 GitHub 正式发布；预览和草稿不会触发更新。

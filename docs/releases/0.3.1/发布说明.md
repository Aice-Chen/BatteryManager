# Battery Manager 0.3.1

## 本版变化

- 托盘快捷面板使用工具窗口类型，避免被按普通窗口状态调整任务栏的工具计入；打开面板时重复检查该标志。
- 登录 Windows 和自动更新完成后只在托盘运行，手动打开程序仍显示主窗口。升级会为已登记的本程序启动项补上后台启动参数，保留 Windows 的启用或禁用状态；托盘图标持续不可用时会显示主窗口。
- 设置页按“通用”和“关于”组织，自启动提示更简洁。更新使用一个随状态切换的按钮，配合版本、下载进度和失败原因显示；自动更新开启时不在设备页重复提示可用新版。
- 修复安装前检查失败后恢复旧版 0.3.0 的兼容性：恢复原程序时使用旧版支持的启动方式，避免因新参数无法识别而保持关闭；安装成功后的新版仍在托盘运行。

## 升级与边界

0.3.0 已开启自动更新的用户会按既有检查周期获取本版，也可在设置页手动检查和安装。自动检查在启动 30 秒后开始判断，此后每小时判断一次，两次自动尝试至少间隔 24 小时。

升级沿用安装位置并保留个人设置；卸载删除个人设置、备份、日志和更新缓存，用户自行放入安装目录的其他文件保留。程序与安装器仍未代码签名，附带 MIT 及第三方许可。

本版没有扩展外设协议。隔离测试不等同于真实 Windows 注销后登录验收；任务栏工具的具体规则仍由各工具决定。

## 验证

823 项代码测试、139 项发布工具检查、45 项应用管理检查、73 项界面交互检查及 28 项隔离安装器检查通过。管理检查使用真实按钮点击事件，覆盖后台启动与重复启动；旧版恢复回归用例先复现失败，再验证修复。应用场景替换网络、硬件、注册表和安装动作，安装器检查使用独立目录与测试进程。

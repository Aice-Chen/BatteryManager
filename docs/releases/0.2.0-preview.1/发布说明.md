# Battery Manager 0.2.0-preview.1

Windows 11 x64 安装与更新框架预览。

## 新增

- 当前用户安装版，可选择安装目录；升级沿用原位置，卸载保留个人配置。
- 设置页增加登录自启开关，显示 Windows 禁用状态，并可打开系统启动设置。
- 每天最多一次正式版本自动检查，可关闭；支持手动检查、下载、取消及完整性校验。
- 安装版下载后由用户确认安装，完成设置保存和设备通信退出后交接安装器。
- 便携版继续使用 ZIP 更新；安装版可以从用户选择的便携目录导入配置，已有配置不会覆盖。

## 内部整理

- 采集器明确提供连接方式，共享 HID 枚举与操作排空流程，私有协议仍限定已验证型号。
- 设置、存储、更新协调和自启规则集中在 Application 层，可以脱离窗口测试。
- 便携包、安装器、更新清单和发布材料按版本统一生成，并相互核对来源与文件摘要。

## 使用与限制

安装版数据位于 `%LocalAppData%\BatteryManager`；便携版数据仍在程序目录。`settings.json` 保存设备设置，`management.json` 保存自动检查偏好及检查时间。两类数据不写入发行包。

自动检查只访问本项目 GitHub 正式发布，不会自动下载、自动安装或升级至预览版。GitHub 无正式发布时显示没有可用新版；网络失败显示错误并允许手动重试。

自启项受 Windows 启动应用设置控制；登记路径与系统允许启动是两个状态。移动便携版位置后需要重新登记。

安装器与应用尚未进行代码签名。下载摘要验证文件完整性，来源信任依赖 GitHub 和 HTTPS。

本轮采用隔离安装、进程交接和模拟管理交互验证；真实 Windows 重新登录、日常便携配置迁至安装版及线上新旧正式版升级尚未验收。此版本保留预览标记。

# Battery Manager 0.2.1

## 修复

修复手动关联设备后，电量来源在“蓝牙电池服务”和“Windows 设备属性”之间反复切换的问题。原逻辑将关联组内所有读数按读取完成时间竞争，Windows 新读取会临时替换仍有效的蓝牙主动读取，随后蓝牙返回又切回。

现在先在每条原始设备记录内按既有质量规则选择电量来源，再在不同关联记录之间选择读数。同一原始蓝牙记录的多个端点也共同参与内部选择。主动读取失败时仍可回退到有效 Windows 电量，恢复后重新使用主动读取。

跨关联记录的连接优先、旧值期限、断开处理和真实电量更新继续遵循既有规则。来源标签、百分比及充电状态来自同一份实际选中读数，不平滑或隐藏设备本身报告的电量变化。

## 安装与更新

提供 Windows 11 x64 当前用户安装器。已有 0.2.0 安装版可在设置页“检查更新”，下载并确认安装；升级沿用原安装目录，保留 LocalAppData/BatteryManager 中的现有设置。

公开附件包含安装器、SHA256 摘要、更新 manifest 和本说明；内部构建 ZIP 不作为便携版发布。程序和安装器尚未代码签名。

## 验证范围

本问题由正式 Core 与显示投影的模拟数据复现；定向回归覆盖来源稳定、失败回退与恢复、多端点及关联成员选择。模拟读数不能替代本机逐轮硬件抓包。真实 Windows 登录自启复测仍按使用者安排延期；它与本次电量来源修复独立。

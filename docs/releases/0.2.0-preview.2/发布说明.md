# Battery Manager 0.2.0-preview.2

此版本用于安装与更新验收，尚未作为 GitHub 正式更新发布。

- 增加仅显式启用的本地更新验收模式：可用真实安装包验证下载、校验、配置保存、程序退出及安装交接。正常启动不启用此模式。
- 增加安装版目录导入的代码验收入口，沿用正式无覆盖规则。
- 新构建记录完整 Git 提交与两份源码摘要，发布前逐文件绑定到指定提交。
- 增加 Windows CI 工作流与可在本机运行的统一入口。

安装版配置保存在当前用户应用数据目录；便携版原目录及配置不会因导入而删除。自动检查仅发现 GitHub 正式发布，下载和安装仍由用户操作。

本阶段未扩展设备协议、修改电量/连接状态规则或重做界面。真实 Windows 登录自启与 GitHub 实际发布下载需分别验收；本地更新响应不能证明线上链路。安装包及程序尚未进行代码签名。

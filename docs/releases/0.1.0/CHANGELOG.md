# 0.1.0 · 2026-11-10

首个正式便携版本，Windows 11 x64。

- 提供外设电量主窗口、托盘数字和快捷面板。
- 支持 Windows 蓝牙电量、标准蓝牙电池服务，以及已验证的 ATK A9 Ultimate、Lofree Flow Lite100、迈从 G3 A 接收器和罗技 K380 蓝牙读取。
- 提供托盘优先级、设备重命名、类型选择、主题和手动连接关联。
- 保留原始电量及短期旧值，处理断连、重连、休眠恢复与首次活跃准入。
- 使用“石墨”软件图标，补全窗口图标与图像流的资源释放。
- 延续 preview.17 已完成的界面对齐，不为单个系统图标增加专用位置补偿。
- 增加正式版本打包、完整性校验、来源记录和第三方许可归档。

已知边界与更新方法见同目录《发布说明》。

# Battery Manager 0.1.0

版本日期：2026-11-10。适用系统：Windows 11 x64。发行形式：便携 ZIP。

首个正式版提供本地外设电量列表、托盘电量数字和快捷面板。

## 功能

- 自动读取 Windows 报告的蓝牙电量，并补充标准蓝牙电池服务及已验证外设的厂商读取。
- 托盘按用户设定的优先顺序显示可用设备电量；高优先设备恢复后自动回切。
- 自定义设备名称、类型和主窗口颜色；托盘外观跟随 Windows 模式。
- 从设备卡片菜单手动合并同一设备的不同连接，合并操作支持受配置冲突保护的撤销。
- 处理断开、重连和系统睡眠恢复；保留短期旧电量，并在到期后显示“—”。
- 使用“石墨”软件图标，覆盖程序文件、主窗口标题栏和托盘面板底部。

## 支持范围

| 读取方式 | 当前范围 |
|---|---|
| Windows 设备电量 | 系统能提供连接与电量信息的蓝牙设备 |
| 标准蓝牙电池服务 | 已连接且提供可读取 BAS 的低功耗蓝牙设备 |
| ATK 接收器 | 本机验证的 A9 Ultimate，接收器 373B:11D9 |
| Lofree 接收器 | Flow Lite100 / OE922，已验证接口与固件 |
| 迈从接收器 | G3 A，接收器 A8A5:2255，已验证接口与固件 |
| 罗技蓝牙厂商读取 | K380，046D:B342 |

厂商支持以表内已验证型号、接口和连接方式为界。其他型号是否提供可用的系统电量或标准电池服务，取决于设备和驱动实际报告。

## 电量与连接显示

本次程序运行中，设备须先确认活跃才能进入列表。启动时休眠的外设可能需要唤醒一次。已确认连接但尚无有效电量时显示“—”。

灰色电量是此前成功读到的旧值，最多保留 15 分钟；失去响应后显示“暂无响应”，超过既定等待期后隐藏。接收器的部分状态同时出现在闲置和关机时，因此这两种状态仍按已有证据处理。

显示保留设备原始报告。迈从和 Lofree 曾在开机附近出现短暂电量跳变；K380 报告的是设备分档代表值。换 USB 插口可能产生新的连接记录，可通过设备菜单手动关联。

## 安装、更新与退出

完整解压 ZIP 到可写文件夹，运行 `BatteryManager.App.exe`。包内已包含所需运行库，请保留全部文件。关闭主窗口后程序继续在托盘运行；从托盘菜单选择“退出”结束程序。

从预览版更新时，先退出旧版，把正式版解压到另一个文件夹；如需保留配置，在首次运行前复制旧目录的 `settings.json`，并保留已有 `settings.v1.bak`、`settings.v2.bak`。0.1.0 沿用 v3 配置格式；旧格式首次明确保存时会先备份再升级。

当前版本需手动启动。设置保存在程序所在文件夹，电量采集在本机完成。异常诊断文件会写入同目录的 `logs` 文件夹。

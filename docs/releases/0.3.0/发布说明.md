# Battery Manager 0.3.0

## 自动更新

安装版默认自动检查 GitHub 正式新版，下载并校验后保存设置、正常退出、静默安装并重新启动。托盘隐藏时也能执行。可在设置页关闭“自动更新”，原来关闭“自动检查更新”的设置会继续保持关闭；原来开启的设置会启用本版完整自动流程。

启动 30 秒后判断检查资格，之后每小时判断一次；两次自动尝试至少间隔 24 小时，失败也计入间隔。手动检查、下载和确认安装仍可使用。安装提交前，关闭自动更新或取消操作会停止尚未提交的自动任务。

安装交接会等待配置保存及外设读取结束，再等待原进程退出。自动更新的安装前检查失败且原进程已正常退出时，在安全校验通过后尝试重启未改写的原程序；成功安装后启动新版一次。更新保留设备名称、关联、托盘优先级、主题和 Windows 启动许可。

## 清理与卸载

升级按原安装文件清单清理新版不再使用的文件，保留用户自行放入安装目录的其他文件。新版启动后清理旧版本安装包和中断下载；文件暂时被占用时有限重试，仍失败则记录并在下次启动再尝试。

**卸载将删除个人设置及其备份、日志、更新缓存，以及本安装拥有的启动登记。** 这是与 0.2.1 的行为变化；重新安装后需要重新设置名称、关联和托盘优先级。

清理会校验文件归属和路径，防止旧目录卸载器影响另一当前安装。中断的清理记录可供再次安装恢复。开始写入后的磁盘或提取故障不保证完整回滚，必要时需重新运行安装包修复。

## 安装与许可

支持 Windows 11 x64。现有 0.2.1 用户需要通过原程序的“检查更新 → 下载新版 → 安装更新”或运行新版安装包完成这一次升级；升级后才具备全自动更新能力。保持原安装位置即可沿用设置。

安装包附带项目 MIT 许可证；字体和第三方依赖保持各自许可。程序与安装器尚未代码签名。公开附件为安装器、SHA256 摘要、更新 manifest 和本说明，内部构建 ZIP 不作为便携版发布。

## 验证范围

功能提交通过 818 项代码测试、139 项发布工具检查、38 项真实 WinUI 模拟边界检查，以及 47 项真实隔离 Inno 安装测试。后者覆盖三版本升级后卸载、自启保护、文件占用、清理中断重试、取消交接、等待退出与一次重启。

隔离测试使用独立安装目录和注册表子树；它们不等同于日常安装版已完成从 0.2.1 升级、真实 Windows 登录自启或任意磁盘故障回滚验收。此次没有扩大外设协议支持范围。

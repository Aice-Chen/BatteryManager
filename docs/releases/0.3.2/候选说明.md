# 0.3.2-preview.1 候选说明

该候选将 Microsoft.WindowsAppSDK 从 2.6.4 更新至同一系列的补丁版 2.6.5，采用微软对多显卡或多显示器环境中绘制错乱的修正。现有界面布局、采集协议、设置和更新行为保持原有实现。

相关症状包括：连接外接显示器后，托盘面板文字或图标残缺、内容串到其他位置，收起后再次打开仍然异常。[微软 2.6.5 修复说明](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/release-notes/windows-app-sdk-2-0?pivots=stable#version-265)及[上游问题记录 #12434](https://github.com/microsoft/microsoft-ui-xaml/issues/12434)与此报告相符；本项目尚未完成显示器连接变化过程的前后对照，不能把上游修正直接等同于本机原故障已验收。

本地已完成 Release 构建、110 项应用逻辑检查、73 项界面交互及 45 项管理界面检查。测试使用独立场景，替换硬件、配置及安装动作。在当前双屏环境中移动并调整候选主窗口后，125% 与 150% 缩放的窗口截图正常，125% 托盘面板的深浅主题截图正常。

这是未公开的安装验证候选，后续需核对更新后的日常程序以及显示器连接变化后的显示结果。程序及安装器尚未代码签名。

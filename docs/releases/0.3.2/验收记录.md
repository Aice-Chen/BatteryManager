# 0.3.2 验收记录

0.3.2 将 Microsoft.WindowsAppSDK 从 2.6.4 更新至同一系列的补丁版 2.6.5，采用微软对多显卡或多显示器环境中绘制错乱的修正。现有界面布局、采集协议、设置和更新行为保持原有实现。以下本机安装及显示验收使用 0.3.2-preview.1，正式版本沿用相同功能代码与运行库。

相关症状包括：连接外接显示器后，托盘面板文字或图标残缺、内容串到其他位置，收起后再次打开仍然异常。[微软 2.6.5 修复说明](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/release-notes/windows-app-sdk-2-0?pivots=stable#version-265)及[上游问题记录 #12434](https://github.com/microsoft/microsoft-ui-xaml/issues/12434)与此报告相符。

本地已完成 Release 构建、110 项应用逻辑检查、73 项界面交互及 45 项管理界面检查。测试使用独立场景，替换硬件、配置及安装动作。在当前双屏环境中移动并调整候选主窗口后，125% 与 150% 缩放的窗口截图正常，125% 托盘面板的深浅主题截图正常。

已在本机将日常安装版从 0.3.1 覆盖升级到该候选：567 个负载文件逐项摘要匹配，26 个旧依赖文件已清除，个人配置及系统自启动状态保持不变，系统卸载登记和实际加载的运行库均已更新。用户确认新版托盘面板收起后再次打开，文字和图标显示正常。

2026-11-22 用户进一步实测确认：切换显示器、拔下并重新连接显示器后，显示均正常。本机验收已完成；上述物理操作结果来自用户报告，未作为跨硬件或驱动版本的普遍保证。

修复分支的 GitHub 自动检查已通过 823 项代码测试、离线发布工具检查和 Release 构建。本轮临时配置与安装信息备份已删除，正式配置保持原字节。程序及安装器尚未代码签名。
